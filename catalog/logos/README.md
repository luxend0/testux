# Distro logos

`<id>.svg` is the logo of the catalog entry with that id. Testux shows it on the distro's
card and detail page. Logos built into the app load instantly; for an id without a built-in
logo the app fetches `catalog/logos/<id>.svg` from `main`, so a new distro only needs its
logo added here.

The names and logos are trademarks of their owners. Testux shows them only to identify each
distro and implies no endorsement.

Every file was cleaned with svgo (editor metadata removed) and given a tight, square viewBox.
Other changes are listed per file.
